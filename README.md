# KiWireManager

KiCad回路図のネットを取り込み、ネット単位で3桁の線番を割り当てるWindows用GUIツールです。

## ダウンロードと起動

1. [GitHub Releases](https://github.com/cotechworks/KiWireManager/releases)を開きます。
2. 対象バージョンの「Assets」から、dist配下のファイルをまとめた配布用アーカイブをダウンロードします。「Source code」は配布用実行ファイルではありません。
3. アーカイブを、書き込み可能な任意のフォルダーへすべて展開します。
4. 展開先の `KiWireManager.exe` をダブルクリックして起動します。

**exeだけを取り出さず、同梱ファイル・フォルダーをまとめて保持してください。** PythonやNuitkaのインストールは不要です。回路図の取込・書込にはKiCad 10を別途インストールしてください。

設定は「設定」ダイアログの「OK」でexeと同じフォルダーの `settings.json` に保存されます。線番JSON・回路図は利用者側で用意してください。

## 操作

1. ネット名と接続元・接続先の機器番号・端子番号を入力して「追加」を押します。1行が物理電線1本です。
2. 「3桁通し番号を採番」を押すと、ネットの初出順に001〜999を割り当てます。同じネットの電線では線番を共有します。
3. 行を選択してネット名や端子を編集し、「選択行を更新」で確定します。線番欄は表示専用です。ネット名変更は選択行だけに適用されます。
4. 再採番は全ネットを振り直します。ネット名未設定は保留し、999ネット超過時は変更せず停止します。
5. 「検証」で未設定・3桁線番・同一ネット内の番号統一・別ネット間の番号重複・端子情報不足を確認します。
6. 「保存」でJSONを保存し、「開く」で再開できます。保存形式はバージョン3です。旧バージョン1・2も読込でき、IDと線番を保持します。バージョン1のネット名は空欄なので、行ごとに指定してください。旧採番設定も互換性のため保存しますが使用しません。
7. 「CSV出力」でネット名を含む配線表を出力します。UTF-8 BOM付きです。検証エラーがあれば出力しません。途中のデータはJSON保存できます。

入力欄は「追加」「選択行を更新」で確定してください。未確定の入力は保存されません。
新規・読込・終了時には、登録済みデータや採番設定の未保存変更を確認します。
CSVはデータ交換用です。機器名などに表計算ソフトが数式と解釈する文字を含む場合、文字列として取り込んでください。

## KiCadフォルダー取込

「設定」ボタンで開くダイアログの「1端子のネットを取り込む」で、1端子ネットの登録を切り替えられます。
初期値はオフ。「OK」で確定し、次回の取込から適用します。キャンセル・閉じるでは変更しません。
「OK」で起動ファイルと同じフォルダーの `settings.json` に保存し、再起動後も引き継ぎます。Python実行時はkiwiremanager.py、exe配布時はexeのあるフォルダーが保存先です。
登録済みの行はオフにしても削除しません。キャンセルでは保存しません。
設定ファイルがなければ初期値オフを使用し、最初の「OK」でファイルを作成します。読込失敗時は警告して初期値を使い、保存失敗時はエラー表示して変更前の設定を維持します。
除外した1端子ネットは新規電線登録と接続先未確定の警告から外れます。シート階層や実際の参照不足は引き続き表示します。

同じpinfunction（機能名）でもピン番号が異なれば別端子として扱います。
ピン番号が未設定の場合は、対象シンボルのリファレンス名を表示して取込を止めます。KiCadで番号を設定してから再取込してください。
JSON・CSVの端子項目には識別用のピン番号を保持します。

1. 「KiCadフォルダー取込」で `.kicad_sch` を含むフォルダーを指定します。
2. サブフォルダーも検索し、ルートを自動判定します。複数ルートは個別に読み込みます。
3. 取込完了時に全ネットを電線一覧へ一括登録します。端子がA・B・Cの順ならA→B、B→Cの仮配線を作成します。順序はXMLネットリストの出現順です。
4. 「不足・警告」でフォルダー外参照・参照先不足・読込エラーを確認します。フォルダー外の子シートは読み込みません。循環参照では取込を停止します。
5. 「シート階層」「不足・警告」はメイン画面のタブで表示します。別の取込ダイアログは開きません。
6. 「電線一覧」で必要に応じて端子対を修正し、「3桁通し番号を採番」で全ネットを採番します。同じネット内の複数の電線は同じ線番になります。
7. 仮配線は実際の施工経路を確認したものではありません。接続元・接続先の情報を保持しているため、今後の機能追加や手動修正に利用できます。

ネットリストはKiCad 10の `kicad-cli sch export netlist --format kicadxml` で取得します。[KiCad公式CLI資料](https://docs.kicad.org/10.0/en/cli/cli.html)
Windowsでは標準インストール先のKiCad 10を探し、それ以外はPATH上のkicad-cliを使用します。
元回路図は変更せず、許可された子シートだけを参照する一時コピーから取得します。不足がある場合、取得できる範囲のネット情報であることに注意してください。
1端子のネットは接続元だけの行、0端子のネットは端子空欄の行として登録し、「不足・警告」に接続先未確定と表示します。
端子情報が未確定でも採番とJSON保存は可能です。配線表CSVは端子情報不足がある場合に出力しません。必要な接続先を指定してから出力してください。
再取込では同じネット・同じ端子対（逆向きも含む）を重複追加しません。既存の電線ID・編集内容・線番は保持し、新規行は未採番で追加します。

機器名はリファレンス名のみ（例：PLC1）とし、回路図ファイル名・パスを含めません。ネット名にはルート回路図の絶対パスを前置して区別します。
ネット名の画面表示・CSVにはファイル名・パスを含めません。内部識別とJSONにはルート情報を保持します。回路図を別の場所へ移動すると取込時の識別名が変わります。
JSONで保存するのは登録した電線です。階層・警告は保存しないため、必要時は再取込してください。新規作成・JSON読込では以前の階層・警告をクリアします。

## 配線の種類による採番対象の設定

1. KiCadフォルダーを取り込み、「配線の種類」タブを開きます。
2. 回路図の配線に保存された線のスタイル・線幅・線の色（RGBA）の組み合わせを一覧表示します。初期値はすべてチェックありです。線幅はmmで表示します。
3. 採番しない種類のチェックを外します。同じネットに複数の種類がある場合、**すべての種類がオフの場合だけ、そのネット全体を除外**します。
4. 除外したネットはアプリ内の線番を直ちに空欄にし、以後の採番でも番号を割り当てません。電線行・接続情報は保持し、CSVには線番空欄で出力します。端子情報不足などの検証は引き続き行います。
5. 回路図へ書込済みの線番は「回路図へ書込」で削除します。確認画面に削除件数が表示され、バックアップ後に管理UUIDのテキストとJSONの対応情報を削除します。利用者作成のテキストは対象外です。
6. 再びチェックを入れた場合は「3桁通し番号を採番」で番号を割り当て直してください。回路図へ再表示する場合は「回路図へ書込」を実行します。

チェック状態とネット・配線の種類の対応はプロジェクトJSONに保存し、読込時に復元します。`settings.json`には保存しません。再取込でも既知の種類のチェック状態を保持し、新しい種類はオンで追加します。新規プロジェクトではリセットします。
以前のJSONに設定がない場合、除外なしで読み込みます。この設定を保存したJSONは更新版アプリで開いてください。

「既定」や幅0は図面に保存された指定として扱い、表示テーマ・ネットクラスの設定で置き換えません。数値表記の違い（0.25と0.2500等）は同じ種類とします。[KiCadのstroke定義](https://dev-docs.kicad.org/en/file-formats/sexpr-intro/#_stroke_definition)に基づき読み取ります。
配線のないネットや未対応のバス構成など、種類を特定できないネットは自動除外しません。タブ下部の件数と「不足・警告」を確認してください。

## 回路図への線番書込

1. 最初の確認は回路図フォルダーのコピーで行ってください。新規プロジェクトでコピーを取り込み、採番してJSONを保存します。
2. 「回路図へ書込」を押します。JSONを開き直した場合やKiCadで図面を変更した場合は、先に図面を再取込してください。
3. 追加・更新・削除件数、対象図面、対象外・警告を確認して実行します。キャンセル時は書き込みません。
4. 配線がある各ネット・各シートに1箇所、3桁線番を通常テキストとして追加します。長い水平配線の上側を優先し、なければ垂直配線の右側へ配置します。文字サイズ・間隔の初期値は1.27mmです。
5. 元回路図一式とJSONを `backup/日時/` に保存・検証した後、元の回路図とJSONを直接更新します。回路図は元の階層構成、元JSONは `_project.json`、処理記録は `writeback.json` に保存します。
6. KiCadで位置を調整した場合は保存後に再取込してください。以降の更新はUUIDで同じテキストを探し、位置・字体・向きを維持して番号だけ変更します。
7. 管理対象テキストの内容がアプリ内の線番と異なる場合は、アプリ内の線番で更新します。位置・向き・文字サイズ・UUIDは保持します。KiCadで図面を変更した場合は先に再取込してください。管理UUIDが消えていれば再作成するか確認します。未管理のテキストは同じ番号でも変更しません。採番除外による削除では、文字の手動変更時の競合チェックを維持します。

削除済みテキストのネットが現在の図面に存在しない場合や配置位置を特定できない場合は、その再作成を保留して「不足・警告」に理由を表示します。他の配置可能なテキストは再作成できます。再取込では旧ネットの登録データを保持するため、図面でネットを変更した場合はこの警告が出ることがあります。保留分のUUID対応情報は残し、配置候補が得られた後に再作成できます。

書込前の一時コピーをKiCadで検証し、ネット接続が不変であることを確認します。未採番・線番不整合・図面変更・参照不足・バックアップ失敗時は書き込みません。
配線のないネットや、座標・ネットの対応を確定できない部分は対象外として表示します。バスを含むシートや、複数配置された共用シートでネットが異なる場合にも制限があります。
自動配置の重なり回避は保証しないため、KiCad上で見た目を確認してください。取込時の仮配線順ではなく、回路図上の配線を配置根拠にします。

途中失敗はバックアップから復元を試みます。復元も失敗・強制終了した場合は、次回の書込で未完了処理を検出し復元を案内します。処理後に別途編集したファイルは復元で上書きせず停止します。
バックアップを変更・削除せず、エラーに示す保存先を保持してください。複数ファイルをOSレベルで一括原子更新する保証はありません。

プロジェクトJSONの `annotations` に線番テキストの対応情報（sheet、text_uuid、net_key、last_written_number）を保存できるようにしました。
同じネットでも表示箇所ごとに記録を保持できます。旧形式は対応情報なしで読み込みます。旧版アプリでは形式3を読み込めないため、旧JSONを残す場合は「名前を付けて保存」を使用してください。
書込完了時に対応情報と前回書込線番を更新します。通常の新規プロジェクトでは、最初に書き込むまではannotationsは空配列です。

python -m unittest discover -s tests -v
python tests/gui_smoke.py
python tests/gui_import_tabs.py

## 現在の操作：ネット単位の3桁通し番号

ネット名と線番を別項目として扱います。
登録・ネット名変更後に「3桁通し番号を採番」を押してください。一覧のネット初出順に001〜999を割り当て、同じネットの全電線に共有します。
例：+24Vを2行、0Vを1行登録すると001・001・002になります。
再採番は全ネットを振り直します。999ネットを超える場合は変更せず停止。ネット名未設定は保留し既存線番を保持します。
旧JSONの番号も読込時は保持し、採番操作時に新方式へ変更します。線番欄は表示専用です。
CSV出力にはネット名、001〜999の3桁、同一ネット内の番号統一、異なるネット間の番号非重複、端子情報の検証通過が必要です。
