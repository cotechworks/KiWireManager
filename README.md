# KiWire Manager（仮称）

Python 3.10以降とTkinterを使用する独立した線番管理GUIです。追加Pythonパッケージは不要です。回路図取込にはKiCad 10が必要です。

## 起動

Windowsでは `start_kiwiremanager.bat` をダブルクリックして起動できます。
エラー時にはコンソールが開いたままになり、内容を確認できます。

このフォルダーで次を実行します。

```powershell
python kiwiremanager.py
```

## 操作

1. ネット名と接続元・接続先の機器番号・端子番号を入力して「追加」を押します。1行が物理電線1本です。
2. 「3桁通し番号を採番」を押すと、ネットの初出順に001〜999を割り当てます。同じネットの電線では線番を共有します。
3. 行を選択してネット名や端子を編集し、「選択行を更新」で確定します。線番欄は表示専用です。ネット名変更は選択行だけに適用されます。
4. 再採番は全ネットを振り直します。ネット名未設定は保留し、999ネット超過時は変更せず停止します。
5. 「検証」で未設定・3桁線番・同一ネット内の番号統一・別ネット間の番号重複・端子情報不足を確認します。
6. 「保存」でJSONを保存し、「開く」で再開できます。保存形式はバージョン2です。旧バージョン1も読込でき、IDと線番を保持します。旧データのネット名は空欄なので、行ごとに指定してください。旧採番設定も互換性のため保存しますが使用しません。
7. 「CSV出力」でネット名を含む配線表を出力します。UTF-8 BOM付きです。検証エラーがあれば出力しません。途中のデータはJSON保存できます。

入力欄は「追加」「選択行を更新」で確定してください。未確定の入力は保存されません。
新規・読込・終了時には、登録済みデータや採番設定の未保存変更を確認します。
CSVはデータ交換用です。機器名などに表計算ソフトが数式と解釈する文字を含む場合、文字列として取り込んでください。

## KiCadフォルダー取込

端子選択ではpinfunction（機能名）とピン番号を併記します。同じ機能名でも番号が異なれば別端子です。
ピン番号が未設定の場合は、対象シンボルのリファレンス名を表示して取込を止めます。KiCadで番号を設定してから再取込してください。
JSON・CSVの端子項目には識別用のピン番号を保持します。

1. 「KiCadフォルダー取込」で `.kicad_sch` を含むフォルダーを指定します。
2. サブフォルダーも検索し、ルートを自動判定します。複数ルートは個別に読み込みます。
3. 取込画面の「シート階層」で子シート配置を確認します。同じファイルの複数配置は別々に表示されます。
4. 「不足・警告」でフォルダー外参照・参照先不足・読込エラーを確認します。フォルダー外の子シートは読み込みません。循環参照では取込を停止します。
5. 「ネットと端子」でネットを選び、接続元・接続先の異なる端子を選択して「電線として追加」を押します。
6. 必要な電線を追加したら取込画面を閉じ、メイン画面で採番・保存・CSV出力します。

ネットリストはKiCad 10の `kicad-cli sch export netlist --format kicadxml` で取得します。[KiCad公式CLI資料](https://docs.kicad.org/10.0/en/cli/cli.html)
Windowsでは標準インストール先のKiCad 10を探し、それ以外はPATH上のkicad-cliを使用します。
元回路図は変更せず、許可された子シートだけを参照する一時コピーから取得します。不足がある場合、取得できる範囲のネット情報であることに注意してください。
1端子だけのネットも一覧に表示しますが、電線登録には同じネット内の2端子が必要です。
物理電線は利用者が明示的に定義します。登録済みの同じ端子対は重複追加しません。

機器名はリファレンス名のみ（例：PLC1）とし、回路図ファイル名・パスを含めません。ネット名にはルート回路図の絶対パスを前置して区別します。
JSON・CSVにもこの名前を保持します。回路図を別の場所へ移動すると取込時の識別名が変わります。
JSONで保存するのは登録した電線です。取込画面の全ネット一覧・階層情報は保存しないため、必要時は再取込してください。

## 未実装の範囲

回路図への書き戻し、GitHubライブラリ同期、Excel形式、複数芯ケーブル専用管理は未実装です。
物理配線の経路は利用者が定義します。ネットから自動推定しません。
電線行の削除機能は含みません。

```powershell
python -m unittest discover -s tests -v
python tests/gui_smoke.py
python tests/import_smoke.py "回路図フォルダーのパス"
```

GUIスモークテストにはデスクトップ表示環境が必要です。

## 現在の操作：ネット単位の3桁通し番号

ネット名と線番を別項目として扱います。
登録・ネット名変更後に「3桁通し番号を採番」を押してください。一覧のネット初出順に001〜999を割り当て、同じネットの全電線に共有します。
例：+24Vを2行、0Vを1行登録すると001・001・002になります。
再採番は全ネットを振り直します。999ネットを超える場合は変更せず停止。ネット名未設定は保留し既存線番を保持します。
旧JSONの番号も読込時は保持し、採番操作時に新方式へ変更します。線番欄は表示専用です。
CSV出力にはネット名、001〜999の3桁、同一ネット内の番号統一、異なるネット間の番号非重複、端子情報の検証通過が必要です。
