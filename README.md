# KiWire Manager（仮称）

Python 3.10以降とTkinterを使用する独立した線番管理GUIです。追加パッケージは不要です。

## 起動

Windowsでは `start_kiwiremanager.bat` をダブルクリックして起動できます。
エラー時にはコンソールが開いたままになり、内容を確認できます。

このフォルダーで次を実行します。

```powershell
python kiwiremanager.py
```

## 操作

1. 接続元・接続先の機器番号と端子番号を入力して「追加」を押します。1行が物理電線1本です。
2. 接頭辞・開始番号・最小桁数を設定し「自動採番」を押します。
3. 既存線番を保持し、使用済み番号を飛ばしながら一覧順に未採番の電線へ割り当てます。桁数は最小幅です。例：接頭辞W、開始1、桁数3ならW001。
4. 修正する場合は行を選択し、入力欄を編集して「選択行を更新」を押します。線番を空欄に更新すると、その電線を再採番できます。
5. 「検証」で不足項目・重複・未採番を確認します。
6. 「保存」でJSONプロジェクトを保存し、「開く」で再開できます。設定と電線IDも保持します。
7. 「CSV出力」で配線表を出力します。CSVはExcelで開きやすいUTF-8 BOM付きです。未採番・重複・端子情報不足がある場合は出力しません。

入力欄は「追加」「選択行を更新」で確定してください。未確定の入力は保存されません。
新規・読込・終了時には、登録済みデータや採番設定の未保存変更を確認します。
CSVはデータ交換用です。機器名などに表計算ソフトが数式と解釈する文字を含む場合、文字列として取り込んでください。

## 初版の範囲

KiCadファイル取込・回路図への書き戻し、GitHubライブラリ同期、Excel形式、複数芯ケーブル専用管理は未実装です。
物理配線の経路は利用者が定義します。ネットから自動推定しません。
電線行の削除機能は含みません。

## 検証

```powershell
python -m unittest discover -s tests -v
python tests/gui_smoke.py
```

GUIスモークテストにはデスクトップ表示環境が必要です。
