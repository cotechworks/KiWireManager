## 4. 既知の問題・制約

- KiCad連携、GitHub同期、Excel形式、電線削除は含まない。
- 入力欄は「追加」「選択行を更新」で確定する。未確定入力は保存対象外。
- 最小桁数を超える番号は桁が増える。
- 機器の実在や配線の電気的妥当性は判断しない。
- サンドボックス内ではTkが起動できなかったが、通常実行環境のGUIスモークは成功。
- CSVは入力文字列を保持する。表計算ソフトが数式と解釈する入力は文字列として取り込む。
